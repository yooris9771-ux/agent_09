# mk-ppt

이 저장소 안에서 python-pptx(1.0.2)로 .pptx를 생성·수정·분석하는 절차다. 프로젝트 규칙(CLAUDE.md)의 TODO 선보고·승인 후 실행 규칙을 그대로 따른다.

## 1. Python 실행 경로

Python 3.13은 사용자 범위로 설치되어 있다. 현재 셸에 PATH가 반영되지 않았으면 `python`이 Microsoft Store 바로가기로 연결되어 실패하므로, 먼저 확인하고 안 되면 전체 경로를 쓴다.

- PowerShell: `& "$env:LOCALAPPDATA\Programs\Python\Python313\python.exe"`
- Bash: `"$LOCALAPPDATA/Programs/Python/Python313/python.exe"`

python-pptx가 없다는 오류가 나면 같은 인터프리터로 `-m pip install python-pptx`를 실행한다. 이 문서의 `python` 예시는 모두 위 경로로 바꿔 실행한다.

직접 작성하는 생성 스크립트에도 맨 앞에 `sys.stdout.reconfigure(encoding="utf-8")`를 넣는다. Windows 콘솔 기본 인코딩(cp949)에서 한글 경로·텍스트 출력이 깨지기 때문이다.

## 2. 작업 흐름

1. **요구 파악** — 슬라이드 수, 주제, 원본 자료(예: `research/<주제>/round<N>/*.md`), 비율(기본 16:9), 템플릿 유무를 정리한다. 원본 자료가 있으면 먼저 읽고 슬라이드별 개요를 TODO에 포함해 보고한다.
2. **생성 스크립트 작성** — 일회성 생성 스크립트는 scratchpad에 둔다(저장소를 어지럽히지 않기 위해). 기능별 코드 패턴은 `references/api.md`를 참고한다.
3. **실행 및 저장** — 산출물은 아래 저장 규칙의 경로에 저장한다.
4. **검증** — `scripts/inspect_pptx.py <파일>`로 다시 열어 슬라이드 수, 제목, 텍스트가 의도대로인지 확인하고 결과를 사용자에게 요약한다. 파일이 열리지 않거나 텍스트가 비어 있으면 원인을 고친 뒤 다시 검증한다.

## 3. 산출물 저장 규칙

- 경로: `ppt/<주제>/<발표자료명>_<N>차[_YYYYMMDD].pptx` (폴더명은 영문 소문자+하이픈, 파일명은 한글 가능)
- 기존 파일을 덮어쓰지 않고 차수를 올린다.
- `ppt/` 폴더나 새 주제 폴더를 처음 만들면 CLAUDE.md의 "폴더 구조" 섹션과 `translate/CLAUDE.md`를 함께 갱신한다.

## 4. 디자인 기본값

일관된 결과를 위해 따로 요청이 없으면 다음을 쓴다.

- 슬라이드 크기 16:9 (`Inches(13.333)` × `Inches(7.5)`)
- 한글 글꼴 `맑은 고딕` — 지정하지 않으면 한글이 기본 서양 글꼴로 대체되어 어색해진다. run 단위로 `font.name`을 지정한다.
- 제목 32~40pt, 본문 18~24pt, 슬라이드당 글머리표 5~6개 이하 — 그 이상이면 슬라이드를 나눈다.
- 첫 장은 제목 슬라이드(제목·부제·날짜), 마지막 장은 요약 또는 결론.
- 수치 데이터가 있으면 문장 나열 대신 표나 차트로 보여 준다.

## 5. 기능 범위 요약

자세한 코드는 `references/api.md`에 영역별로 있다. 필요한 절만 읽는다.

| 영역 | 가능한 작업 |
|---|---|
| 파일 | 새로 만들기, 열기, 저장(경로/BytesIO), 슬라이드 크기, 문서 속성, 템플릿 기반 시작 |
| 슬라이드 | 레이아웃 지정 추가, 순회, 배경, 발표자 노트, 레이아웃 이름 검색 |
| 도형 | 자동 도형, 텍스트 상자, 그림(자르기), 표, 차트, 동영상, 연결선, 그룹, 자유형, OLE, 플레이스홀더, 회전, 그림자, 하이퍼링크 |
| 텍스트 | 문단·run, 글꼴, 정렬, 간격, 여백, 자동 맞춤, 하이퍼링크 |
| 표 | 셀 값, 병합/분할, 열 너비·행 높이, 셀 채우기, 스타일 옵션 |
| 차트 | 막대·꺾은선·원형·도넛·영역·분산·거품·방사형, 데이터 교체, 축, 범례, 데이터 레이블, 계열 서식 |
| 서식 | 단색·그라데이션·패턴 채우기, 테마 색, 선 서식 |
| 읽기·분석 | 텍스트·이미지·표·차트 데이터 추출, 찾아 바꾸기 |
| 저수준 | `._element`로 XML 직접 편집 |

## 6. 공식 API가 없는 작업

- **슬라이드 삭제·복제·이동** → `scripts/slide_ops.py` 사용 (`python`은 1절의 전체 경로로, 번호는 1부터)
  - `python .claude/skills/mk-ppt/scripts/slide_ops.py delete <in> <out> <번호>`
  - `python .claude/skills/mk-ppt/scripts/slide_ops.py duplicate <in> <out> <번호>` — 복제본은 원본 바로 뒤에 들어간다. 차트는 독립 복사되고, 발표자 노트는 텍스트만 복사된다.
  - `python .claude/skills/mk-ppt/scripts/slide_ops.py move <in> <out> <원래번호> <새번호>`
- **애니메이션·전환 효과** → XML 직접 편집이 필요하므로 사용자에게 수작업 권장 여부를 먼저 묻는다.
- **SmartArt, 섹션, 댓글, .ppt(구형식)** → 지원 불가. 도형 조합으로 대체하거나 .pptx 변환을 안내한다.
- **이미지/PDF 렌더링** → LibreOffice 등 외부 도구가 필요하다. 설치되어 있지 않으면 `inspect_pptx.py` 텍스트 검증으로 대신한다.
